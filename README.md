# Ceia de Natal 2026 | Toca do Coelho

Portfólio da ceia: o cliente escolhe os pratos e o pedido abre pronto no WhatsApp.

- Preços e pratos: `catalogo.js` (em centavos). A fonte é o PDF do cardápio.
- Regras do pedido e texto da mensagem: `pedido.js`.
- Tela: `index.html`, `app.js` e `styles.css`.
- Testes: `node --test pedido.test.js`.

Site estático, publicado pelo GitHub Pages. As encomendas se encerram sozinhas depois de 22/12/2026, no horário de Brasília.
